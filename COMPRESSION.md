# HyperZip Compression Specification

## 1. Standards-Compliant PKZip Structure

Archives generated by HyperZip follow the standard PKZip format:

```
[Local File Header 1]
[File Data 1 (Deflated or Stored)]
[Local File Header 2]
[File Data 2 (Deflated or Stored)]
...
[Central Directory Header 1]
[Central Directory Header 2]
...
[End of Central Directory Record (EOCD)]
```

### Magic Signatures:
- **Local File Header**: `0x04034b50` (`PK\x03\x04`)
- **Central Directory Header**: `0x02014b50` (`PK\x01\x02`)
- **End of Central Directory (EOCD)**: `0x06054b50` (`PK\x05\x06`)

---

## 2. Checksum Integrity

Every file entry is verified with an IEEE 802.3 32-bit cyclic redundancy check (CRC-32) computed over the uncompressed stream using a 256-entry lookup table.
Standard decompression tools (Windows Explorer, macOS Archive Utility, 7-Zip, Linux `unzip`) will verify CRC-32 integrity before extracting.
